1. git init -b main
   Initializes a new empty Git repository in the current directory with 'main' as the default branch name.

2. git status
   Displays the current state of the working directory and staging area, showing tracked, modified, and untracked files.

3. git add index.html about.html
   Stages the specified files (index.html and about.html) to prepare them for the initial commit.

4. git commit -m "Initial commit: Add index.html and about.html"
   Records a snapshot of the staged files to the repository history with an informative commit message.

5. git diff
   Shows the line-by-line differences between the working tree and the staging area (or latest commit) before staging.

6. git add index.html
   Adds the modified index.html file to the staging area for the second commit.

7. git commit -m "Update index.html with navigation bar and footer"
   Saves the modified index.html into the Git commit history as the second commit on the main branch.

8. git branch feature
   Creates a new branch named 'feature' pointing to the current commit without switching to it.

9. git switch feature (or git checkout feature)
   Switches the working directory and HEAD pointer to the 'feature' branch to begin isolated development.

10. git add about.html
    Stages modifications made to about.html while working on the 'feature' branch.

11. git commit -m "Feature: Add navigation, mission section, and contact info to about.html"
    Commits the changes made in about.html specifically to the 'feature' branch.

12. git switch main (or git checkout main)
    Switches the active branch and working tree back to the 'main' branch before initiating the merge.

13. git merge feature --no-ff -m "Merge branch 'feature' into main"
    Merges the 'feature' branch into 'main' using a non-fast-forward merge, creating an explicit merge commit to preserve branch topology.

14. git log --graph --oneline --all
    Displays the commit history across all branches in a visual graph format with concise one-line commit summaries.

15. git status --ignored
    Displays repository status while explicitly listing files that are ignored by rules defined in .gitignore.

16. git add .gitignore
    Stages the newly created .gitignore configuration file so that ignore rules are tracked in version control.

17. git commit -m "Add .gitignore to exclude *.log files and temp/ directory"
    Commits the .gitignore configuration file to the main branch.

18. git add experimental.html
    Stages a temporary or unintended file to demonstrate an undo operation.

19. git commit -m "Add experimental feature (unintended commit)"
    Records the experimental commit that will subsequently be undone.

20. git revert HEAD --no-edit
    Creates a new commit that records the exact inverse of the latest commit (HEAD), safely undoing changes without altering existing commit history.
    (Note: git reset --soft HEAD~1 or git reset --hard HEAD~1 can also be used locally to roll back the commit pointer).

21. git remote add origin https://github.com/Sid13SST/git-workflow-assignment.git
    Associates the local Git repository with the remote repository hosted on GitHub under the alias 'origin'.

22. git branch -M main
    Ensures the active branch is named 'main' prior to pushing to GitHub.

23. git push -u origin main
    Uploads all commits from the local 'main' branch to the remote GitHub repository and sets 'origin/main' as the upstream tracking reference.

24. git push origin feature
    Pushes the 'feature' branch to GitHub so instructors can inspect both branches directly in the remote repository.
